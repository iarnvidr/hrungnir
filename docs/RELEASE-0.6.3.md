# Hrungnir 0.6.3

Tall videos now fit the window height, with room for controls and surrounding UI. Portrait previews/players keep their proportions and stay centered; landscape players retain the available width. The height limit adjusts with the element-size setting.

Native Linux regression checks cover portrait height/aspect ratio, landscape width, local previews, playback/seek, settings and tab controls. Apple Silicon build/signature/resource verification is recorded in the progress notes. Native macOS runtime verification remains pending.
