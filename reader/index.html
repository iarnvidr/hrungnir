Keyboard shortcuts

Subreddits, search results and post lists
j/k or Down/Up move without opening. l/Right or Enter opens the focused item. h/Left moves from posts to the subreddit navigator; l/Right enters that community’s posts.
Tabs and search
Shift + H/K or Shift + Left/Up switches to the previous tab; Shift + J/L or Shift + Down/Right switches to the next. On a subreddit tab these switch communities. ⌘L / Ctrl+L and / focus search. Set post and subreddit tab orientations independently in Settings. Library is in the toolbar.
Inside a post
j/k move between visible comments. l expands replies or enters a child. h collapses replies, moves to the parent, then returns to the post list. From the post heading, h returns immediately. Enter follows focused links.
Search
/ focuses search. Enter runs it; use j/k and l to explore results. Escape leaves the search field without discarding results. Use Clear to reset the search.

Shortcuts do not run while typing or when a dialog is open. Tab and Shift+Tab remain available for every control. Cmd+, opens Settings.

Media stays local. Inline players load on request and never autoplay.

Text size changes type independently. Element size changes controls and spacing. Inline media uses the available width, keeps its aspect ratio, and remains uncropped.

Unwatched downloaded media follows the post lifetime. Videos watched to 95% expire after 24 hours by default; subreddit groups can override both lifetimes. Keep video protects its post and completed media.

Post cache

Starts when posts are captured and media finishes downloading. Fully watched videos use a separate 24-hour default. Keep video protects the post and completed media; storage pressure can still remove unprotected media sooner.

Subreddit groups

Each subreddit belongs to one group. Forever applies to that group’s cached posts or watched media.
